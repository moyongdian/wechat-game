# 摸鱼小游戏 —— 聊天贪吃蛇

微信小程序。首页伪装成聊天列表，列表里的「用户」其实是小游戏名称；点「贪吃蛇」进入一个**聊天窗口样式**的贪吃蛇游戏页。

- 平台：微信小程序（原生，不用 Taro/uni-app）
- 渲染：Canvas 2D + `setTimeout` 游戏循环
- 数据：全部本地存储，**无后端、无需登录、不收集隐私**
- 进度：**V1.1**（按《小游戏功能说明书.md》实现）

## 快速开始

1. 微信开发者工具 → 导入项目 → 目录选**仓库根目录**（含 `project.config.json`）
2. AppID 使用 `project.config.json` 中已配置的 `wx461db390b6650bea`，或换成你自己的
3. 编译运行。无需「构建 npm」，无第三方依赖

## 游戏规则

**三种模式**（说明书 §6.1）

| 模式 | 边界 | 自身 | 速度 |
|---|---|---|---|
| 经典 | 撞墙死亡 | 撞自己死亡 | 随分数加快 |
| 穿墙 | 左右/上下互通 | 撞自己死亡 | 随分数加快 |
| 限时 | 撞墙死亡 | 撞自己死亡 | 固定中速，60 秒倒计时 |

**特殊豆**（说明书 §6，概率 25%，可在设置关闭）

**特殊豆**（概率 27.5%，可在设置关闭；形状 / 大小 / 颜色各不相同）


| 豆 | 形状与颜色 | 效果 |
|---|---|---|
| 金豆 | 金色圆（大） | +5 分 |
| 双倍豆 | 白色方块「×2」 | 20 秒内吃豆得分翻倍 |
| 减速豆 | 蓝色圆 | +3 分，8 秒内移动变慢 |
| 磁铁豆 | 黑色圆 + 白色磁铁图标 | +3 分，15 秒内自动吸附附近豆子 |
| 红包 | 红色圆角矩形（最大，金边） | +10~50 随机分，屏幕弹红色分数 |

基础规则：初始 3 节、向右、定时移动、豆子不会生成在蛇身上、限制 180° 反向、同一 tick 只接受一次转向。

**分数段与连击**：分数达到 **50 / 100 / 200 / 400** 进入新阶段，每个阶段

- 蛇速提升一档（同时分数本身也会平滑加快，间隔下限 60ms）
- 吃豆得分翻倍（连击倍率 ×2 / ×4 / ×8 / ×16，顶栏显示「×N 连击」）

**蛇身渲染**：各节之间用粗圆头线段相连，任意走向（直行/拐弯）都完全无缝；
穿墙时跨边界的相邻节会断开绘制，避免出现横穿画面的长线。

**平滑移动**：逻辑按网格步进，渲染在两个 tick 之间插值，
因此蛇看起来是连续滑动而不是一格一格跳。

**音效**：普通吃豆与特殊豆各有一声音效（本地 wav，默认关闭，可在设置开启）。

## 伪装设计（说明书 §9）

- **老板键**：双击消息区（或点顶部聊天对象名称）立即暂停并隐藏蛇与豆子，显示普通聊天气泡；再次触发恢复
- **假消息**：消息区低透明度装饰气泡，频率可调（低/中/高）
- **伪装文案**：退出确认框显示「确定删除该聊天？」；结算弹窗伪装为「消息发送失败」，按钮为「重新发送 / 返回聊天」
- **状态展示**：顶部左侧返回箭头旁的游标数字即当前分数；最高分在底部栏
- **默认静音**：音效默认关闭，避免声音暴露

## 工程结构

```
miniprogram/
├── app.js / app.json / app.wxss
├── images/                      # 原创头像与 Tab 图标（PNG，脚本生成）
├── utils/
│   ├── snake-engine.js          # 贪吃蛇内核（纯逻辑，可单元测试）
│   ├── settings.js              # 设置与最高分本地存储
│   ├── fake.js                  # 假消息与伪装文案
│   └── util.js                  # 震动/音效/间隔计算
└── pages/
    ├── index/                   # 首页：类微信聊天列表
    ├── game/snake/              # 游戏页：聊天贪吃蛇
    └── settings/                # 设置：聊天信息页样式
```

## 校验（无需开发者工具）

```bash
node tools/test-engine.js    # 游戏内核单元测试（46 项，对照说明书规则）
node tools/check.js          # 静态校验（结构/引用/标签闭合/事件/资源）
```

游戏内核之所以拆成独立模块（`utils/snake-engine.js`），就是为了能在 Node 中直接跑规则测试 ——
46 项断言覆盖三种模式、7 种特殊豆、速度曲线、特殊效果、暂停恢复与边界情况。
